Derived by `/context-constitution` (context-forge) on 2026-07-24; last refreshed 2026-11-13 (`ccr-7e428591-3j2he0` @ `52f6d5a`). This file captures the **non-obvious** — patterns this repo follows but never

already say or CI already enforces (see `## Pointers`). Refresh by re-running `/context-constitution`.

> **ID scheme (CF-N5).** The repo already has an SDD Constitution (`docs/sdd/constitution.md`,
> prefixes `C-*`/`P-*`/`F-*`) that governs **process/workflow** (review gates, branch policy, the SDD
> pipeline). The rules below are **codebase/runtime invariants** — a different *kind* of rule — so they
> use a sibling namespace `PLAT-*` and cross-reference the SDD IDs where they overlap, rather than
> renumbering into the process scheme. Per-module constitutions use `<MODULE>-*`.

## Gotchas & scars

- **Python config getters honour a stored `0`/`""`; a key where `0` is unsafe must read through a clamp (feature 244).** In analysis, ingest, indicators and the agent, `get_int/get_str/get_float` live in the shared `app/config/watch_core.py` core (`WatchCore._typed`, byte-identical across the four — see Pointers) and use `HasField` (like `get_bool` and the Node `??` getter), so a stored `0`/`0.0`/`""` is the effective value and only an absent or mismatched-type value falls back to the default. The old `*_present` names are kept as `watcher.py` aliases. A key where `0`/`""` would break the consumer (a `Semaphore(0)`, a `sleep(0)` busy-loop, a zero pool size or range, an empty id) is read through the module-level `int_positive`/`float_positive`/`str_nonempty`, which map a stored ≤ 0 (or `""`) to the default. The analysis, ingest and indicators `tests/test_config_read_classification.py` AST guard (the agent has none) fails when a new config read is in neither its clamp set nor its honour set, so a new key needs a deliberate classification. Evidence: `services/xstockstrat-analysis/app/config/watch_core.py#_typed` (~L202, `HasField` ~L206) and `#get_int` (~L217); `services/xstockstrat-analysis/app/config/watcher.py#get_int_present` (aliases ~L66-67) and `#int_positive` (~L72); `services/xstockstrat-ingest/app/config/watcher.py#int_positive` (~L143); `services/xstockstrat-indicators/app/config/watcher.py#int_positive` (~L106); `services/xstockstrat-analysis/tests/test_config_read_classification.py#FR3_KEYS`; Node `services/xstockstrat-ledger/src/services/configWatcher.ts#getInt` (~L209); oneof `packages/proto/config/v1/config.proto#ConfigValue` (~L60).
