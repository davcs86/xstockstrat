## Objective

A staging-only HTTP service runs a catalog of named checks (phase 1: DB reads and read-only RPCs; phase 2: owner-scoped writes as a non-admin smoke user) after each staging deploy on homelab and DO dev, and records every attempt as a file on a `smoke-results` branch tied to the deployed SHA. Triggers: homelab post-deploy step, DO `POST_DEPLOY` job, and an admin-gated agent tool.
