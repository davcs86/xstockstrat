**Scars & gotchas**: CI-vs-local font-metric divergence at desktop widths — the Step 23 1024px overflow test passed locally (0px) but failed deterministically in CI at ~18px because the repo ships no bundled webfont (system font-fallback metrics differ between sandbox and GitHub Actions Chromium), and it was the first overflow test ever run at a desktop (≥lg) width; the real offender was a pre-existing, feature-unrelated PlatformHeader Row 1 tightness edge case. SidebarProvider's generated wrapper defaults to flex min-h-svh w-full and defaultOpen=true — wired unmodified it passed build/lint but broke e2e (min-h-svh stretched the wrapper past Row 1's h-[49px], pushing the trigger below the viewport; defaultOpen=true left a fixed md:flex-visible panel); fixed with `<SidebarProvider defaultOpen={false} className="w-auto min-h-0">`.
