## Archive Synthesis — 2026-09-02 — /sdd-archiver

**What**: Feature 023 shipped `PlaceOrderRequest.confidence` + a `qty<=0` auto-sizing path but deliberately shipped it backend-only and inert. 110 is the named C-14 follow-up that gives that wire a real caller: it adds `optional double signal_confidence = 19` to `analysis.Opportunity`, populates it from the raw per-signal `ExternalSignal.conviction`, and threads it into the live signal-detail order ticket (`OrderForm` at `trader/positions/[symbol]/page.tsx:342`) via a scoped blank-qty affordance that routes into 023's auto-sizing. It also deleted an orphaned component + a redirect stub in-scope. Stacked on feature 095's proto block (field 19 follows 095's 13–18).

**Why (irrecoverable rationale)**: The value had to come from raw `ExternalSignal.conviction` (the `_best_sig_conv` max-reducer), NOT the sibling `Opportunity.conviction` (a doc-commented ordinal, "NOT a probability") and NOT `signal_axis` (decayed × source-weighted) — three same-shaped 0–1-ish candidates, only one semantically correct; the field was named `signal_confidence` (not `confidence`) to stop a future reader repeating the collision. The affordance is gated on a present, finite, in-[0,1] confidence specifically because a held/watchlist-only/off-queue symbol has no signal → offering blank-qty there would silently default confidence to 1.0 (full risk), which was 023's own explicitly-rejected footgun.

**Rejected alternatives**: wire `Opportunity.conviction` (ordinal — name+range match, meaning doesn't); wire `signal_axis` (decayed × source-weighted, not the raw 0–1 the ACs assert); a targeted `GetSignalConfidence` read RPC (a second divergent source, C-10(b); the page already fetches the `Opportunity`, so a field is zero-new-fetch); scope the affordance on `initialSymbol` (the plain `/trader` symbol page also passes it — would leak blank-qty into non-signal tickets; used an explicit `signalConfidence` prop mirroring `allowOfflineRecord`); a new `analysis.opportunities` column (deferred to no-migration JSONB carry to avoid C-07 + DBA gate for one scalar).

**Scars & gotchas**: JSONB is mandatory, not optional — a top-level row key is silently dropped by `replace_for_user`'s fixed INSERT column list, so the value MUST ride `readiness_json` (mirroring feature 132's `muted`), populated at candidate row-build and carried in `_row_to_opportunity`. NaN-qty trap: `parseFloat('')` = `NaN`, and Go's `NaN <= 0` is false, so a naive "blank = auto-size" would bypass the `qty<=0` gate and send `NaN` to the broker — blank must be coerced to a real `0`. Verification-grep over-match: the AC-9 delete-verification `! grep -rn "insights/market"` over-matched a surviving comment in a preserved sibling test; narrowed to `! grep -rn "goto('/insights/market"`.
