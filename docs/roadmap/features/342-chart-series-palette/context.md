**What**: The symbol-page indicator chart (`/trader/positions/[symbol]`) now draws every series in its own colour: 12 `--series-1..12` tokens, with the same `rgb()` values in `staging.css` and `production.css` (kept byte-identical by convention; the enforced rule is `colorsEqual`, +-1 sRGB / +-0.01 alpha), one `seriesSlots` array (whole-chart running index mod 12) drives both the canvas line colours and the legend swatches, and a new `colorVision.cjs` (Machado severity-1.0 + CIEDE2000) backs the colour-blind floors in `themes.test.ts`.
