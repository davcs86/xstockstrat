## Archive Synthesis — 2026-11-04 — /sdd-archiver

**What**: SEV-2 bug fix in `xstockstrat-analysis` (one production file, `app/engine/fundsignal_loop.py`). The fundamentals signal producer no longer scores, ranks or emits a symbol that has no usable fundamentals: `_builtin_score` returns `None` instead of the fabricated `0.5` when nothing is usable, `_score` / `_score_via_formula` return `(scores, unscored)`, and one run-attributed WARN (`_warn_unscored`) lists the skipped symbols. Absence is read from `Fundamentals.missing_metrics` (proto field 18), so a real reported 0.0 is now scored (ZRO `roe=0.0` scores 0.30, buggy code gave 0.6 via `if f.roe:`). Under a configured scoring formula a row is skipped only when all six fed keys are missing. No proto, migration, config or ingest change. Launched 2026-10-30 (PR #1368, commit df521ff51091a86e813950b34afff09ac4e8821b). Source defect report: `docs/reports/2026-10-19-analysis-fundsignal-neutral-score-fabricated-defect.md` (pruned 2026-11-04; git show 9892b610:docs/reports/2026-10-19-analysis-fundsignal-neutral-score-fabricated-defect.md) (sidecar `triaged ref: feature:246-fix-fundsignal-neutral-score`).
