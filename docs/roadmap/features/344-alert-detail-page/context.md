## Archive Synthesis — 2026-11-18 — /sdd-archiver

**What**: Every alert has a linkable page at `/accounts/notifications/<alert_id>` (xstockstrat-ui) backed by an additive `notify.v1.GetAlert` RPC (header-only identity; one code-5 `alert not found` for missing, not-visible and malformed ids). Opening the page marks the alert read after a successful load; the title of an inbox row and of a drawer row link to it; the push payload carries `url`; the header Alerts bell moved into `PlatformHeaderInner` so it, with its badge, is on every page of every segment (FR-8); every alert read model sits under the `['alerts']` react-query prefix; ingest's backfill-failure alert body is plain language (`<CODE> — <details>`) where the alert keeps the raw `str(e)` only in `context["error"]` (the backfill job row and the `ingest.backfill.failed` ledger payload are unchanged and still hold raw `str(e)`). No migration, config key, env var or new edge. Integration PR #1557 (squash commit `89f513f6` on main-dev, commit date 2026-11-16; no source gives a merge date); launched 2026-11-17 via promotion PR #1573.
