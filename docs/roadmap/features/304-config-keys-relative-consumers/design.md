## Chosen Approach

**Shape.** One integration PR carrying 12 commits (operator decision, context.md 2026-11-08): 11 service-family commits, then one finish commit (Cf). There is no gate-prep commit. Each family commit is one service step plus its test step, run as a unit (the 295 test-blast-radius lesson, `fails.md` 295 entry). Order: ledger, identity, notify, portfolio, marketdata, indicators, ingest, analysis, agent, trading, ui, Cf. The order is not load-bearing for green-ness; the drain rule below is.

**Rewrite rule.** Every getter, `SetConfig`/`GetSecret` key and key constant becomes the key relative to the namespace its watcher subscribes to. Runtime display strings (WARN/log text, error and reject strings, MCP tool text, `formulaReference.ts`) keep the FQN because C-05 makes the FQN display-only; the shared cores' `fqn()`/`_fqn()` re-prefix a relative key for WARN text (recon: "Display-only FQN helper already relative-safe"). Docs list (namespace, relative key). Shared watcher cores, applied migrations and event/metric names are never touched (recon: Out of scope).

**Per family commit** (all together, so no literal is separated from its double or its doc): production literals, constants and `registry.dynamic`/`registry.receivers` rows; every modelling test and fixture through the service's canonical double, with the S2 guard added to that double; the service `CLAUDE.md` banner and "Config Keys Consumed" table; and deletion of exactly the `prefixed-read` baseline entries the ratchet would otherwise report `STALE`.

**Drain rule.** Baseline entries carry no `file` (`sameId` accepts that, `check-config-wiring.mjs:700`), so a shared id is still produced while any reader stays prefixed. An entry therefore drains in the commit of the LAST reader; deleting it earlier is RED, keeping it later is STALE (`ratchet` `:704-718`). ## Rejected Alternatives

- One shared `trading`+`platform` watcher with a collision detector or a gate-only guard — rejected (operator steering S1): first-hit-wins `lookup` lets a runtime `trading`/`trading_state` row silently override HALTED/maintenance; the gate cannot see runtime rows and a detector only reports.
- Nil-safe `platformCfgW` accessor serving a zero Watcher — rejected: a zero watcher never WARNs, a missed wiring would be a silent HALTED (feature-192 outage signature); a required non-nil constructor argument fails boot loudly.
- Namespace-scoped getter in trading `config.go` — rejected: duplicates the core's typed decode and `recordRead`/warn logic (C-18 DRY) for a collision S1 already removes.
- `attribute()` resolving list receivers from the stored set with zero matches → first namespace — rejected: contradicted FR-4 "zero stays null", could hide a typo under the wrong namespace; moot once trading has no list receiver. Deleting list-receiver support was also rejected: not required, and 305 FR-3 / merge-order row 30 rely on it.
- Gate-prep commit C1 (`DOC_SCAN_PENDING`, `alt` in `excluded()`) — rejected: temporary scaffolding that is never removed (`fails.md` 2026-10-07), and widening the doc scan early is red while the 11 banners still contain the banned "cutover in feature 296". The scan widens in Cf only.
- A second Go constructor beside `NewSnapshotWatcher`, or a `WithSnapshot` method — rejected: leaves an unguarded path; the `Must…` rename makes every stale call a compile error and `ApplyUpdate` already serves single-namespace watchers.
- `internal/testdata/` as the Go double's home — rejected: import cycle with package `config`'s tests; the canonical constructor stays in `internal/config/config.go`.
- Normalising prefix-catalog rows in `excluded()` (FR-4 original) — dropped with operator sign-off: the only real prefix row (`catalog.tsv:100`) is already relative; AC-10 becomes characterization-only.
- Deleting `config_allow296.py` in 304 — rejected: keeps 304 a pure consumer rewrite; 305 owns it (operator decision).
- Routing the poller `SetConfig` through `platformCfgW` — rejected (runner-up): changes no behaviour because the namespace travels in the request; only widens the diff.
- Sharing one gRPC connection between the two trading watchers — rejected: needs a core edit; per-namespace connection fault domain accepted.
- Bumping the strat-lab plugin version — rejected (YAGNI); not required by `docs/patterns/strat-lab-plugin.md:16-22,54-55`.

## Open Risks

- [ ] A trading test struct literal that reaches `PlaceOrder`/`ReplaceOrder`/the halt gates without `platformCfgW` nil-panics at `trading.go:443`; `trading_offline_test.go:601` wraps the call in `defer recover()`, so that one test would fail with a misleading message — to be addressed at the trading commit (rule: every literal or helper that sets `cfgW` also sets `platformCfgW`; pin `trading_offline_test.go:585` and assert `platformCfgW != nil` first).
- [ ] Ad-hoc lambda/MagicMock doubles stay outside S2, so the 295 silent-default trap survives wherever a value equals the code default — mitigated per family by a grep over every test root; list each hit in the step's Files.
- [ ] `maintenance_mode` defaults to `false`, fail-open on that axis; `trading_state` defaults to HALTED and dominates, and boot exits if the platform snapshot is absent — accepted, trading commit.
- [ ] Per-namespace connection fault: only the platform stream can drop, keeping its last `trading_state` (stale ACTIVE possible until the reconnect SNAPSHOT, ≤ ~60 s after config is reachable); WARN `config watcher stream ended, reconnecting namespace=platform` is the signal — accepted; not worse than today's independent per-namespace streams.
- [ ] Rebase collisions with 305/306 on `config-wiring.json`, `check-config-wiring.mjs`, `config-wiring.test.mjs` (merge-order rows 30/31) and a banned phrase added by another feature before merge turns Cf's `--doc-check` red — re-run the gate after each rebase, Cf.
- [ ] jscpd: three `MustSnapshotWatcher` bodies sit near `minTokens: 100` (`.jscpd.json:4`) in non-ignored `config.go` files — keep each a few lines; run `scripts/check-duplication.sh` in each Go family commit.
- [ ] strat-lab files beyond `SKILL.md:81` name prefixed keys as operator knobs (`SKILL.md:127,141,187,228`, `reference/output-handling.md:31`, `verification.md:31`, `aggregation.md:10-11`; line numbers not re-verified by the orchestrator); `SetConfig` rejects prefixed keys. Default: respell all as (namespace, key); /sdd-spec confirms by grep — analysis commit.
- [ ] Portfolio's `go test` opens `scripts/config-wiring-stored.json`; a later regeneration by 305/306 only re-runs portfolio if the CI trigger lists it — Cf adds it.
- [ ] Operator-side confirmation that feature 295's one-staging-release window closed is still recorded as unconfirmed (carried from 296; not a 304 gate).
