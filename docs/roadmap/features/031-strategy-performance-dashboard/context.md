## Archive Synthesis — 2026-09-02 — /sdd-archiver

**What**: Shipped an `/insights/performance` dashboard whose equity-curve/drawdown/rolling-Sharpe/summary math lives entirely in a pure UI lib (`src/lib/performanceMetrics.ts`), sourced from `portfolio.position.closed` ledger events + one-shot `GetConfig`. What began as a zero-backend, UI-only feature grew a second code-bearing surface mid-design: the `xstockstrat-portfolio` producer emit was additively extended with `cost_basis` + `opened_at` because two required summary stats were **not derivable** from the existing event.

**Why (irrecoverable rationale)**: The pivot from UI-only to touching the portfolio producer was an **explicit operator decision on 2026-08-31**, overturning the recon/early-design framing; after deletion, the shipped two-key emit reads as ordinary — the fact that it was a deliberate scope expansion (chosen over deferring the two stats to a V2) survives only here. The producer extension was chosen over reconstructing entry/exit/hold-time from raw `order.filled` fill-pairing in the BFF (that reimplements portfolio's own position-lifecycle bookkeeping); emitting `existing.CostBasis`/`existing.OpenedAt` (fields the producer already has in hand) was cheaper and authoritative. `qty`/`avg_entry_price`/`closed_at` were **deliberately not added** — neither stat needs qty/entry-price, and the event's producer-stamped `OccurredAt` is already the close time + equity-curve ordering key, so avg-hold-time = `occurred_at − opened_at`.

**Rejected alternatives**: lightweight-charts v5 (candlestick engine only, oklch→rgb parse trap ledger-146); daily portfolio snapshots for the Sharpe series (needs snapshotting infra that doesn't exist); a `WatchConfig` subscription (UI is a stateless request/response BFF with no WatchConfig consumer anywhere — `GetConfig` per poll only); BFF fill-pairing reconstruction / a new backend RPC / relocating the math to a service.

**Scars & gotchas**: The portfolio emit lives in a method taking a concrete non-fakeable `*repository.PortfolioRepo` (`internal/service` coverage-excluded) → the payload build was extracted into a pure `closedPositionPayload` helper to get a RED unit test (mirrors 042's `realizedDelta`). `structpb.NewValue` rejects `time.Time` → `opened_at` emitted as an RFC3339 string (the `as_of` precedent). `cost_basis` is total-signed (positive longs / negative shorts) and `realized_pnl` is exact only for long, order-fill-originated positions → the UI avg-return-% divides by `Math.abs(cost_basis)` and guards `=== 0`. Local `pnpm dev` cold-route e2e is flaky (known harness artifact); GREEN was taken against the production bundle via `CI=1 E2E_PREBUILT=1`. Playwright `$`-value assertions collided with recharts Y-axis ticks → added a `performance-summary` testid.

**Permanent deviations**: design said `TradingModeBadge` "shows nothing in production" → shipped a dedicated paper-only `data-testid="paper-trading-label"` span (the badge actually renders a "live" badge, so AC-9/AC-10 needed an unambiguous paper-only element). design assumed leaning on `SignalOrderTicket`'s `AccountProvider` → shipped its own mounted `AccountProvider` (feature 110 removes `SignalOrderTicket`, absent from this branch). design listed 5 base keys on `portfolio.position.closed` → shipped preserves 6 (feature 029's `fees_total`) plus the two new keys.

**Cross-feature signal**: Three features converged on the same portfolio close-emit + UI shell in one window — 029 (`fees_total`, merged first), 031 (`cost_basis`/`opened_at`), 110/043 (`navGroups.tsx`/`nav-reachability.spec.ts`). `portfolio.position.closed` is becoming a shared additively-extended contract; each consumer must presence-check optional keys (legacy/redelivered events omit them).

**Deferred follow-ons**: avg-hold-time unit is days (operator-confirmed), reversible to hours via a one-line display divisor.
