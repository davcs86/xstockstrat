## Archive Synthesis — 2026-10-14 — /sdd-archiver

**What**: Began as a 33-field `[deprecated=true]` proto removal program (Defect 2 of `docs/reports/2026-09-18-deprecated-fields-in-rpc-contracts-defect.md`); shipped as a narrow response-edge omission with every `.proto` untouched. Two deprecated string fields stopped being populated: `Bar.timeframe` (marketdata) and `BackfillJob.timeframe` (ingest); `timeframe_enum` is still co-emitted on both. Everything else was KEEP, EXCLUDE or no-op. Guard-test sets landed for marketdata and for portfolio `Watchlist.symbols`; `buf lint`/`buf breaking` reported no change. `feature.md` Type was relabelled non-breaking at execute. The side effect: the agent's `query_bars` tool (`MessageToDict`) loses its per-bar `"timeframe"` key while `"timeframe_enum"` stays; no agent test or strat-lab skill read it.

**Why (irrecoverable rationale)**:
- Origin: the defect was deliberately kept OUT of the triage bug PR — every removal trips `buf breaking`, a harness session cannot supply the 2-owner + platform-lead approvers, and the report's inventory was only a candidate list.
- Removal/`reserved` lost because it contradicts PROTO-2 (deprecate-don't-delete, no `reserved`), no in-place removal procedure exists (only a v1→v2 package migration), and the module is BSR-published on every deploy so external consumers are presumed.
- At the Round-2 gate the user steered to "filter deprecated fields from the responses, not from the proto definitions". Omission buys reversibility (re-populating is a one-line revert), NOT gate-freedom: omitting a field an external reader still uses is a silent break.
- The FR-3 gate was discharged on 2026-10-08 by operator attestation, not proof: the repo owner (acting as Proto Reviewer + Platform Lead) attested no external consumer reads `buf.build/xstockstrat/contracts` and declared the feature 053/080/143 deprecation window closed. If an external reader ever turns up, re-populate the string at the edges below. The in-repo reader audit was re-run 2026-10-08 on `main-dev` @ `a988b1d6` (the 2026-09-26 audit predated features 211–224).

**Rejected alternatives**:
- In-place removal + `reserved` (original premise) — contradicts PROTO-2, no procedure, breaks BSR consumers, needs 2 owners + platform lead.
- v1→v2 migration — the only documented path but disproportionate for cosmetic dead fields; the honest route if a genuinely smaller published schema is ever required (a new, larger feature).
- Park / deprecate-don't-delete as terminal state — Round 1–2 convergence, superseded by the user steer.
- Omit `Bar.timeframe` at `barFromAlpaca` (`alpaca/client.go:142`) — those bars feed `InsertBars`, which reads `b.Timeframe` (`marketdata_repo.go:71`) to write `ohlcv.timeframe`; `QueryBars` filters on it (`:100`). Omitting there silently corrupts the store and breaks the 400-day GetBars/BatchGetBars scenarios; it would need `InsertBars` to derive the string via `timeframe.ToCanonical` first.
- Omit `Watchlist.symbols` — KEEP: live reader `portfolio_service.go:1691` (`AddWatchlistSymbols` cap uses `existing.Symbols`), second reader `analysis live_loop.py:525` (legacy-row fallback), and the feature-097 old-client mirror.
- Request-only dead fields (10 `user_id` bodies, `is_paper`) — "filter from responses" is a literal no-op because they never appear in responses; identity is header-authoritative (`trading propagation.go:36`). Ingest `operation` is request-only but a LIVE fallback (`servicer.py:75-77,1077`) — it stays.
- Enum values (`TIMEFRAME_*`, `ENVIRONMENT_DEV`, `VALUE_TYPE_FLOAT_MAP`) — a member is not a field you can leave unset; `TIMEFRAME_1MIN` is actively written at `stream.go:255`, `ENVIRONMENT_DEV` rides wire value 1 (`configServiceImpl.ts:28-29`), `15m`/`1h` live in historical rows. Recon found NO numeric-enum columns (timeframe/environment stored as TEXT; config `trading_mode` column dropped by feature 147; `VALUE_TYPE_FLOAT_MAP` key removed by config migration 020), so a future enum-retirement story need not redo that audit. The real hazard: a removed/unreachable member breaks an exhaustive TS `Record`/switch or Go switch, at compile time or silently.
