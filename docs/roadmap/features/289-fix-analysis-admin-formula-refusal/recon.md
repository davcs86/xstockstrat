## Objective

Indicators deliberately refuses an admin executing another user's formula (`PERMISSION_DENIED`, AC-28). Analysis folds that refusal into "indicators outage" on the opportunities path and lets it abort `EvaluateReadiness`. The fix makes the refusal a first-class, visible "unreadable formula" state (distinct from data-unavailable and from a quiet 0/N) on every path that propagates the admin scope, reaching UI and agent consumers, without disturbing the backtest/live-loop mappings, NOT_FOUND skip, or timeout propagation.
