## Archive Synthesis — 2026-10-07 — /sdd-archiver

**What**: Every `analysis.opportunities` row (`user × symbol_norm × strategy_id`) carries a nullable 0-1 `composite_score` (proto field 21, migration 024): a ranking ordinal fusing two axes only — readiness `conviction` and a direction-scoped signal sub-score — with empirical-Bayes shrinkage toward 0.5, computed on the refresh write path and the surgical heal path and shown on `/insights`, `/trader` and `list_opportunities`. Scope is narrower than the story: the operator's "all four evidence types" became two axes after recon showed the others are not distinct axes on this path. `conviction` and `signal_axis` stay separately queryable (never-fold invariant). Launched 2026-09-24 via PR #1169.
**Why (irrecoverable rationale)**: Fusion is across evidence types per opportunity, not across strategies; a symbol-level roll-up was deferred (it became feature 200, which consumes this score). Only two axes: fundamentals re-enters as `ExternalSignal`s feeding `signal_axis` (a fundamentals term double-counts) and technical signal is screener/backtest-only behind the `servicer.py:667` boundary (a new per-symbol RPC would break feature-191 latency). The operator chose "direction-scoped magnitude" over "signed" and over "direction-agnostic", and a 0-1 scalar with no A-F band. The fails.md:313 ordinal-as-probability trap was discharged by declaration, not transformation: readiness uses the identity map and the composite is declared a ranking ordinal (a 1/10 setup scores ~0.1, not ~0.55). k=1.0 with unit weights (pseudo-count = one axis-weight): a single maxed axis lands at 0.750, a corroborated pair 0.833; the operating band is [0.167, 0.833]. "Missing" and "contradicted" are different states: missing evidence goes to the neutral prior, present-but-contradicted evidence is an active pull-down (both-mixed 0.500 < strong-readiness/no-signal 0.750; AC-4 0.433 vs AC-3 0.650). Contested symbols are pulled toward neutral on purpose — the composite is "directional actionable edge", raw activity lives on `signal_axis` (direction-agnostic MAX). Unavailable is not evaluated-low: computed against the real axes before the `sym_unavailable` zeroing, then both weights forced to 0 so Σw=0 persists NULL. Operands are clamped because `source_weights.get(..., 1.0)` can exceed 1 under an operator override. The composite is DISPLAY-ONLY and deliberately NOT the queue sort key: the feature-190 ORDER BY blend and `signal_rank_weight` are unchanged (do not "fix" this by wiring it into ORDER BY; sort-key adoption needs its own feature — feature 200's `symbol_score` is the later opt-in ranking consumer).
**Rejected alternatives**: All four evidence types. A one-sided readiness rescale `0.5+0.5·conv` (inflates weak setups 0.1→0.55, caps the score ~0.667 at k=4). k=4.0 inherited from feature 065 (dimensionally wrong for two unit weights). Linear-cancellation direction discount `max_agree − max_conflict` (parity cliff 0.70/0.70→0). Ratio `a/(a+c)` (scale-free: weak-clean equals strong-clean). `scoring.py` `(net+1)/2` fold (0.5-neutral sum/count basis incommensurable with the MAX-based `signal_axis`; overrides the recon advice at insights.md:1135). A shared `_eb_shrink` extracted from `_aggregate_cells` (touches the ANALYSIS-2 binding grade path; callers weight by different quantities). Asymmetric weights as the default (equal weights keep it distinct from `conviction` and the `signal_rank_weight=0.3` sort; asymmetry is a config change). A config-ui seed migration for the 3 keys (code-default-only like sibling `analysis.scoring.*`). Best-effort try/except persistence (the recon/spec directive) was SUPERSEDED: the composite is one more bound column in the existing `replace_for_user`/`replace_symbols` transactions, so a composite write failure fails the whole replace and does not degrade to NULL.
