## Execution Summary

This feature hardens the **existing** formula subprocess child in `xstockstrat-indicators` with
four layered, unprivileged OS-isolation mechanisms (per `design.md` Chosen Approach): a distinct-UID
child (uid/gid 65534), stdin source delivery, a post-import seccomp-BPF **allowlist**
(`defaction=ERRNO(EPERM)`), expanded `setrlimit` caps plus env-based write elimination, and
`start_new_session` + `killpg` deterministic termination. No proto change, no new config keys, no
migration (design §6). Order: **Step 1** lands the `pyseccomp` dependency + `uv.lock` + the
Dockerfile `libseccomp` packages (a prerequisite the rewrite imports); **Step 2** rewrites
`sandbox.py` (and the one `servicer.py` call site that must pass `max_concurrent` so `RLIMIT_NPROC`
derives from config, F-07); **Step 3** is the paired test module — it also removes `sandbox.py` from
the coverage `omit` list so the security code is finally measured (R5/fails.md:133), covers every
`@AC-*`, and keeps the full pre-existing suite green (FR-4/C-16); **Step 4** reconciles the docs that
describe the sandbox and runs the mandated context-constitution teardown.

**Consumer Surface (C-14):** product spec marks this `None — internal/platform-only` (hardening
behind the existing formula authoring/run capability; FR-4 pins observable behavior identical). No
UI/Agent step is required — this is a decision, not an omission.

### Scenario Coverage (C-15)

| Scenario | Covered by |
|---|---|
| `@AC-1` — escaped formula cannot open outbound network | Step 3 |
| `@AC-2` — escaped formula cannot read secrets / service FS | Step 3 |
| `@AC-3` — infinite-loop / memory-bomb terminated deterministically | Step 3 |
| `@AC-4` — legitimate formula evaluates to identical result | Step 3 |
| `@AC-5` — fork-bomb capped, service stays responsive | Step 3 |
| `@AC-6` — isolation limits are configured, not hardcoded | Step 3 |

> **AC-2 interpretation note (P-03, surfaced not papered):** the approved design realizes AC-2's
> "reads outside scratch denied" as **secret-exfiltration containment**, not a blanket read jail
> (flag-filtered `openat` was a Rejected Alternative, design #7): env-strip (`_sandbox_env`,
> C-4) removes the service secrets; the **distinct UID** makes the parent's `/proc/<ppid>/environ`
> and any service-owned non-world-readable file `EACCES`; and the platform's real secrets are
> `GetSecret`-RPC config rows, not files in this container (design §1). World-readable files that
> hold no secret (e.g. `/etc/passwd`) remain readable — this is by design. The Step-3 test asserts
> exactly this containment, not an unimplemented read jail.

**Codebase Evidence**:

- Current child launch (temp file + `subprocess.run`, `env=_sandbox_env()`) — `sandbox.py:198-210`; temp-file cleanup in `finally` — `sandbox.py:264-268`.

**TDD**: `red-green required`

**Covers**: —

**Instructions**:
1. **`_sandbox_env()` (`sandbox.py:43-55`) — write elimination (design §4).** Add to the returned
   dict: `"PYTHONDONTWRITEBYTECODE": "1"`, `"HOME": "/nonexistent"`, `"TMPDIR": "/nonexistent"`.
   These empirically eliminate all compute-time writes (`.pyc` cache + `~/.cache`/`$TMPDIR`). Keep
   `PYTHONPATH` and `_THREAD_LIMIT_ENV`; keep the secret-strip contract (do not add any secret). Add a
   ≤2-line constraint comment noting these three are the write-elimination env (constants of the jail).
2. **Rewrite `_SANDBOX_WRAPPER` (`sandbox.py:116-172`) — the in-child lockdown, run in the wrapper's
   own single main thread post-`execve`** (NOT `preexec_fn` — Rejected #4). Ordered sequence, all
   BEFORE `exec(source, ...)` (`:166`) and AFTER the existing numeric-lib thread pins already applied
   via env:
   a. Keep the existing `RLIMIT_DATA` cap (`:127-128`, gated on `{memory_bytes} > 0`).
   b. **Eagerly import each allowed module** (iterate the `_allowed` set built at `:131`) in a
      try/except so import-time syscalls (openat dir-walk, `getdents64`, `statx`, `mbind`) run
      **before** the seccomp filter loads (design §3 — load post-import to shrink the surface).
   c. **Drop privileges** (design §1), gated so it is a no-op when already unprivileged (dev/CI):
      `if os.geteuid() == 0:` then `os.setgid(65534); os.setgroups([]); os.setuid(65534)`. uid/gid
      `65534` (`nobody`/`nogroup`) is a fixed constant of the jail — add a ≤2-line constraint note.
   d. `prctl(PR_SET_NO_NEW_PRIVS, 1)` (explicit, though `pyseccomp` also sets it) — via `ctypes`
      libc `prctl` or `pyseccomp`'s default; **invariant: never disable NO_NEW_PRIVS**.
   e. **Expanded rlimits** (design §4), all derived from the config tunables or named safety constants
      with a ≤2-line constraint note each: `RLIMIT_CPU = ceil({timeout_ms}/1000) + 2` (SIGKILL-independent
      CPU backstop); `RLIMIT_NPROC = {max_concurrent} * 16` (fork-bomb bound; derived from
      `indicators.sandbox.max_concurrent` so it scales, never a bare literal — F-07/C-05);
      `RLIMIT_FSIZE = 0` (write-content bound; stdout is a pipe, unaffected); `RLIMIT_NOFILE = 64`.
      Keep `RLIMIT_DATA` from (a). **Do not add `RLIMIT_AS`** (INDICATORS-2).
   f. **Build + load the seccomp allowlist** (design §3): `f = seccomp.SyscallFilter(defaction=
      seccomp.ERRNO(errno.EPERM))`, native arch only (do NOT `add_arch` compat x86/x32 — the allowlist
      must fail closed on other ABIs), then `f.add_rule(seccomp.ALLOW, name)` for each name in the
      finalized allow set (design §3, verbatim list — `openat, read, readv, write, writev, close,
      lseek, fstat, newfstatat, statx, getdents64, mmap, munmap, mremap, mprotect, madvise, brk, mbind,
      set_mempolicy, get_mempolicy, futex, futex_waitv, set_robust_list, get_robust_list, rseq,
      sched_yield, sched_getaffinity, membarrier, clone, clone3, rt_sigaction, rt_sigprocmask,
      rt_sigreturn, rt_sigtimedwait, sigaltstack, restart_syscall, tgkill, clock_gettime,
      clock_nanosleep, nanosleep, gettimeofday, getrandom, getpid, gettid, getuid, geteuid, getgid,
      getegid, prctl, exit, exit_group`). Wrap each `add_rule` in try/except so a name unknown to the
      host libseccomp is skipped (safe — an ALLOW for a nonexistent syscall is inert; the runtime-image
      validation, Step 3 verification (e), confirms the real set). Then `f.load()`. **The whole
      network family, `execve`/`execveat`, `io_uring_*`, `ptrace`, `process_vm_readv/writev`, `pidfd_*`,
      and write-creating FS ops are deliberately absent → `EPERM`** (design §3).
   g. `exec(source, _formula_globals)` unchanged (`:166`) — the user formula runs last, fully locked.
   Store the allow set as a module-level constant (e.g. `_SECCOMP_ALLOW`) so Step 3's structural test
   can import and assert against it (design verification (a)).
3. **Rewrite the parent launch (`sandbox.py:198-210, 264-268`) — stdin + process group (design §2, §5).**
   Replace `NamedTemporaryFile` + `subprocess.run([sys.executable, script_path], ...)` with
   `subprocess.Popen([sys.executable, "-"], stdin=PIPE, stdout=PIPE, stderr=PIPE, text=True,
   env=_sandbox_env(), start_new_session=True)` and `proc.communicate(input=wrapped, timeout=timeout_ms/1000)`.
   This feeds the wrapped program on **stdin** (UID-independent inherited fd) and removes the
   parent-owned `/tmp` script the nobody child could not read (design §2). Drop the `NamedTemporaryFile`
   write and the `os.unlink` cleanup.
4. **Deterministic termination (design §5, load-bearing).** On `subprocess.TimeoutExpired` (existing
   handler `:252-263`), first `os.killpg(os.getpgid(proc.pid), signal.SIGKILL)` then reap
   (`proc.communicate()` / `proc.wait()`) before returning `exit_reason="timeout"`. Additionally, on
   **every** exit path (a `finally`), `os.killpg` the group (guarded against `ProcessLookupError`) so a
   `fork()+sleep(∞)` grandchild cannot survive to hold a uid-65534 `RLIMIT_NPROC` slot forever
   (permanent @AC-5 DoS). Add `import signal` (and `errno`) at module top.
5. **`execute_formula` signature (`sandbox.py:175-182`)** — add a `max_concurrent: int` parameter
   (used only to derive `RLIMIT_NPROC = max_concurrent * 16`; a safe default such as `4` matching the
   config default keeps existing direct callers/tests working). Format it (and the derived rlimit
   values) into the wrapper via the existing `.format(...)` call (`:189-196`).
6. **`servicer.py:170-179`** — pass `max_concurrent=self._cfg.sandbox_max_concurrent()` into the
   `asyncio.to_thread(sandbox.execute_formula, ...)` call so the fork-bomb bound derives from live
   config (F-07). No other servicer change; the `exit_reason` map (`:181-187`) already covers every
   outcome (design §6). This adds **no new outbound gRPC call** — header-propagation constraint N/A.
