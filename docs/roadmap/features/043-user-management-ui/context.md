## Archive Synthesis — 2026-09-02 — /sdd-archiver

**What**: Shipped an admin-only "Users" section in `/config-ui` backed by six additive admin RPCs on `xstockstrat-identity` (`CreateUser`/`ListUsers`/`GetUser`/`UpdatePassword`/`SetUserRoles`/`SetUserActive`), a closed `Role` enum, a password-free `User` view, and a best-effort redacted ledger audit. No DB migration — the `users` table already had `roles TEXT[]`/`is_active`/timestamps. This made `xstockstrat-identity` an outbound gRPC caller for the **first time** (its `AppendEvent` to ledger), which newly binds C-03 to it.

**Why (irrecoverable rationale)**: Reads (`ListUsers`/`GetUser`) are admin-gated too — a deliberate divergence from the config service whose reads are open (driven by AC-7); it reads as an odd inconsistency between two otherwise-identical `authz.ts` ports but was intentional. Refresh-token revocation on `UpdatePassword`/`SetUserActive(false)` is keyed on the **target** user_id specifically to sidestep the `revokeToken` unsigned-decode finding. Identity's `LEDGER_ENDPOINT` + `depends_on` were **already wired** in all three deploy specs even though the identity CLAUDE.md deps table said "ledger dep removed" — the findings-doc note is accurate only for the CLAUDE.md deps table, not the deploy specs; only the reader code was new.

**Rejected alternatives**: open `TEXT[]` role strings at the RPC boundary (roles are a closed `viewer/trader/admin` set — the C-04 enum case, cost: an exhaustive TS `Record<Role,…>` map); a Next.js middleware admin route-guard (scope creep — BFF `forwardAdmin` + identity server gate are both fail-closed, nav `adminOnly` hides the entry, a non-admin deep-linker just sees an empty shell with `PERMISSION_DENIED` RPCs); a synchronous mutation-failing ledger audit (no cross-service transaction — best-effort-after-commit is less brittle than rolling back on a ledger redeploy); naive count-then-mutate last-admin guard (TOCTOU — shipped an atomic conditional `UPDATE` guarded by `EXISTS(other active admin)`).

**Scars & gotchas**: The identity unit suite runs vacuously under `node --experimental-strip-types --test` (parameter-property class won't load; guard swallows; 0% coverage exits 0) — real gate is `tsc` then `node --test dist`. The audit `idempotency_key` must be stable across retries — impl-review caught the spec's `…:${Date.now()}` (defeats ledger dedup), shipped `…:${traceId}` (or empty). Playwright browser-build mismatch (pinned 1234 vs installed 1194) + dev cold-compile `ListUsers` >10s (same as 021 Step 13), worked around with `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` + `--timeout=120000 --workers=1`; `getByText('Inactive')` strict-mode violation scoped to the status Badge. Write-skew residual on the last-admin guard (atomic per-row, but two concurrent demotions of *different* admins can still reach zero under READ COMMITTED — design-accepted R4, needs SERIALIZABLE only if a strict ≥1-admin invariant is required).
