**What**: SEV-3 bug fix (debt-radar D-37, D-38), all in `xstockstrat-ui`; no proto/migration/config/env change. Shipped (promoted via PR #1368, df521ff5, launched 2026-10-30): a leaf `src/lib/deadlines.ts` holding five code constants; the `makeTransport` unary wrapper applies `timeoutMs ?? DEFAULT_UNARY_TIMEOUT_MS` (30s) while the `stream` wrapper and lazy `get()` stay untouched; `refreshSession` is bounded at 10s and fails closed (null -> existing redirect/401 + cleared cookies); six RPCs run at 300s and four order mutations at 60s; `forwardAdmin` takes an additive `{ timeoutMs }`; `middleware.ts` returns early on an exact-match `PUBLIC_HEALTH_PATHS` Set (8 paths) and the `api/health|health` matcher prefixes (which let root lookalikes such as `/healthcheck-x` skip auth) were deleted. **Why (irrecoverable rationale)**:
- Round 1 proposed a 10s default plus a 300s opt-in list; the adversary showed the opt-in list was incomplete (destructive `deleteBackfilledData` was unclassified) and would drift silently as new heavy RPCs were added. Round 2 chose a generous 30s default (precedent `@AC-1 @feature-191`) plus an explicit short bound on the one real hang site (`refreshSession`) and a short long-call list. (design.md@1ed63958:147-148; old context.md@1ed63958:68, 415)
- Refresh bound moved 5s -> 10s: identity's single-use rotation (`identityServiceImpl.ts:228-241`) can commit after the client gives up, so a shorter bound widens the forced-logout window; 10s also kept the original AC-2 wording. (design.md@1ed63958:149, 165-168)
- All deadline constants are code constants, not `ui.*` keys (F-07 record): the UI has no `WatchConfig`, `ui` is a one-shot `GetConfig`, the values are untuned transport mechanics, precedent `FUNDAMENTALS_TIMEOUT_MS`. (design.md@1ed63958:81-85)
- Constants live in a leaf module because `connectClients.ts` cannot import `bffShared.ts` without an import cycle (C-18). (design.md@1ed63958:151)
- Black-hole real-socket test: round 1 rejected it as too costly (two-place port/env wiring, old context.md@1ed63958:193); round 2 made it mandatory (old context.md@1ed63958:390; design.md@1ed63958:154); the spec found the wiring cost zero via an in-process ephemeral port (implementation-spec.md@1ed63958:154).
- Triage recommended design depth `skip` (old context.md@1ed63958:28-31) yet a full two-round debate ran; reason not recorded. Branch syncs used `-X ours` (old context.md@1ed63958:550, 626); process only.
- Why exempting the health paths loses no header propagation: none of the eight handlers makes a backend gRPC call, so skipping the middleware `x-trace-id` injection loses nothing (C-03). (implementation-spec.md@1ed63958:495-504)
