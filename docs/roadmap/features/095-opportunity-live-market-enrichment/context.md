## Archive Synthesis — 2026-09-02 — /sdd-archiver

**What**: Shipped the backend + UI + agent for the market-context extras feature 083 left un-faked. Additive `Opportunity` block 13–18 (`live_price`/`change_pct`/`target_price`/`stop_price`/`sparkline`/`conditions`), a new dedicated marketdata `GetLatestPrice` RPC (latest trade + prior daily close, no extra Alpaca call), read-time enrichment in `ListOpportunities`, UI wiring on the queue cards + `trader/positions/[symbol]` + a client-side R:R/sizing ticket, and a new read-only `list_opportunities` agent MCP tool. `target_price`/`stop_price` ship **wired but render nothing** — no producer exists yet; they light up only when a named follow-up populates `StrategyDefinition.signal_params.{target,stop}`.

**Why (irrecoverable rationale)**: Enrich at **read time, post-ranking**, not in `_compute_opportunities` — this is the load-bearing choice: conviction/`signal_axis`/ORDER BY are computed, persisted, and read *before* enrichment attaches, so the live quote can never reach the ranking hot path (FR-8/AC-14 holds by construction), and a persisted price would be hours stale. `change_pct` is derived in analysis `(last−prev)/prev`, never carried on the marketdata wire. Field 18 (`conditions`) is *used*, not reserved — the readiness trace is already computed, so carrying it to the card costs nothing and keeps feature 110 at field 19+.

**Rejected alternatives**: fields on `Quote` for last-trade/prev-close (served from the `marketdata.quotes` cache which lacks the columns → a cache hit returns a fabricated `0` indistinguishable from "no data"; also bloats the 30s poller → chose a separate `GetLatestPrice` RPC); `repeated double sparkline` (can't represent a gap without `NaN`/`0`, and `MessageToDict` rejects non-finite → `repeated SparklinePoint{optional double close}`, gaps unset); live-price/sparkline on `SymbolReadiness` (a second source breaks C-10(b) parity); server `risk_reward`/`suggested_qty` proto fields (presentation-only, client-side FR-5); derive target/stop from an ATR rule (FR-4 no-fabrication); extend `screen_symbols` for the agent (reads a different RPC carrying none of 13–18 — a new tool was necessary because no existing tool reads `ListOpportunities`).

**Scars & gotchas**: The descriptor-parity guard (`TestOpportunityRowParity`: `_MAPPED | _INTENTIONALLY_UNSET == Opportunity.DESCRIPTOR.fields_by_name`) splits the new fields — compute-time strategy-derived (15/16/18) are persisted in the `analysis.opportunities` row JSONB (no column/migration, rides provenance like `muted` rides `"denied"`) → `_MAPPED`; read-time live-market (13/14/17) set in `ListOpportunities` after ranking → `_INTENTIONALLY_UNSET`. Read-time enrichment broke 4 pre-existing servicer tests that asserted exact downstream call patterns (re-scoped to the compute-path `GetBars`, benign `GetLatestPrice` default). The agent tool-count invariant spans 5 surfaces (32→33). Marketdata new service/handler/repository are coverage-excluded — the only coverable seam is `internal/alpaca/client_test.go` (latest-trade parse) + the pgxmock `execer` seam for `GetPreviousDailyClose`. `GetLatestPrice` reads `prev_close` from the stored prior daily bar (Alpaca's latest-quote returns bid/ask only), bounded by the `_bars_fetch_sem` semaphore + per-pass dedup.

**Permanent deviations**: none material — design committed to single-symbol `GetLatestPrice` (an unchecked Open Risk mused about batching); shipped single-symbol bounded by the semaphore with `GetLatestPricesMulti` as a follow-up.
