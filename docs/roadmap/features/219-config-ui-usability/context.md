## Archive Synthesis — 2026-10-14 — /sdd-archiver

**What**: Config-ui went from a card-grid landing page to a single namespace screen. A shared server `ConfigNamespaceView` sits behind both `/config-ui` and `/config-ui/[namespace]`, with a namespace combobox, env and scope controls and a `NamespaceEditor` that shows each description under its key plus a "row last modified" column. The same change fixed the operator-reported focus-jump bug in the edit form and added `ConfigKeyMeta.updated_at = 10` to the proto and `ListKeys`. Launched 2026-10-03 (integration PR #1207, promotion #1214).

**Why (irrecoverable rationale)**:
- The focus bug was a component-identity problem, not a focus problem: `columns` sat in a `useMemo` whose deps were `editValue`, `editReason` and an unstable `handleSave`; `flexRender` treats each new `cell` function as a new component type, so both `Input`s remounted every keystroke and `autoFocus` re-fired. Module scope fixes this by construction; memoisation, refs and context tricks can't, because `handleSave` is unstable. The old e2e used `.fill()` (one-shot), which never exposed the remount.
- Timestamp semantics are "row last modified" (user's choice, no `value_changed_at` migration): the BEFORE UPDATE trigger bumps `updated_at` on any row update, so a migration UPDATE also moves it. Seed-migration `updated_at` is shown as-is — there is no sentinel to tell "never edited" from "seeded". Revisit only if operators report confusion.

**Rejected alternatives**:
- Redirect `/config-ui` → `/config-ui/platform` — breaks the exact-match Settings › Config `aria-current`, forces review of seven `env-mode-switcher` gotos plus warmup/mobile-overflow/auth specs, and contradicts AC-1's literal URL.
- `useMemo` columns with refs for edit state (fragile; real cause is identity); edit form in a `FormDialog`/expanded row (UX redesign beyond FR-6, C-18); TanStack `table.options.meta` (`DataTable` doesn't forward `meta`, `TableMeta` is untyped); memoising the `EditContext` value (no-op, `handleSave` unstable).
- Deriving "last updated" from `config_audit` (user rejected for the proto field); a `value_changed_at` column (user rejected).
- A namespace filter in the e2e mock (`secret-editing.spec.ts` reads `marketdata.alpaca.api_key` on the platform page → per-spec `page.route` stubs); a global `configUpdatedAtOverrides` stamp in the shared mock (races `value-persists-after-save.spec.ts` under `fullyParallel`); hand-written Connect-JSON stub bodies (`fails.md:677-679`; use `create`/`toJson(XSchema)`).
- Nav `prefix` match for Config (would also activate on `/config-ui/users|audit|…`; exact-path `aliases` built from `KNOWN_NAMESPACES` used instead); resetting `NamespaceEditor` via `useEffect` on `[env, user]` (one frame of stale draft; the `key` remount is atomic).
