## Summary

Replace `xstockstrat-ui`'s hand-rolled Tailwind + Radix `src/components/ui/` primitives with
components generated by the official shadcn/ui CLI (`components.json` + `shadcn add`), and align
the Tailwind theme to shadcn's canonical CSS-variable convention, while preserving the existing
Nocturne dark visual identity and all three frontend segments.
