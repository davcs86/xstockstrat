## Summary

Migrate `xstockstrat-ui` from Tailwind v3 to v4 and fully adopt shadcn/ui's official CLI tooling
using the user's selected preset (`bLTl5gh6`, style `radix-rhea`) — replacing the hand-rolled
`src/components/ui/` primitives, the CSS-variable theme, and part of the dependency stack
(`@base-ui/react`, unified `radix-ui`, `@tabler/icons-react`) — dark-only, no light-mode toggle,
no preservation of the old Nocturne visual identity, across all four frontend segments.
